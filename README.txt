HOW TO PUBLISH ON GITHUB PAGES
1. Create a new GitHub repository (e.g. drammeh-site).
2. Upload everything in this folder: index.html, style.css, README.txt and the images folder.
   (Keep index.html at the top level, not inside another folder.)
3. Repository Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. For your domain: in Pages > Custom domain, enter it, then add the DNS records your
   registrar needs (GitHub shows them). Tick "Enforce HTTPS".

HOW TO EDIT LATER
- Text: open index.html in Notepad and change the words between the tags.
- Colours and fonts: top of style.css.
- Main photo: replace images/portrait.jpg (same file name).
- Gallery photos: add images/gallery-1.jpg, gallery-2.jpg, gallery-3.jpg. They show automatically.
- Videos: find "PASTE VIDEO 1 CODE HERE" in index.html and follow the instructions in the comment above it.
- Email button: find "EMAIL BUTTON" near the bottom and remove the comment marks.
